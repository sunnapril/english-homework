# English Homework Platform

## Version 1.0 — Working

### Infrastructure
- [x] GitHub repository
- [x] Netlify deployment
- [x] Google Apps Script
- [x] Google Sheets results

### Core homework features
- [x] Automatic checking
- [x] Progress saved on the student’s device
- [x] Latest attempt updates the same row
- [x] Student answers stored in Google Sheets
- [x] Expected answers shown for mistakes
- [x] Errors shown before correct answers
- [x] Start time, finish time and duration stored
- [x] Flexible checking of capitalization, punctuation and apostrophes

Supported speaking

Say it first, then write it

25. What is one useful habit you would like to develop?

26. What helps you get things done on a busy day?

Start: On a busy day, … helps me get things done because …
On a busy day, a short list helps me get things done because I can see what is most important.

27. What kind of advice do you find useful?

I find advice about learning languages useful because I can try new ways of studying.

5. Build the questions — then answer them

Roadmap B1 Workbook p.34, Ex.5 · adapted for Egor. Complete each second conditional question. Check the grammar, then give your own answer in 1–2 sentences.

1. What if your internet for two days?
Use would + base verb in the question and Past Simple after if.
What would you do if your internet went down for two days?
2. What sport if badminton courts unavailable for a month?
The situation is imagined, not a real plan for next month.
What sport would you try if badminton courts were unavailable for a month?
3. If you one weekly task, which one ?
Could can describe an imagined possibility; the result question uses would.
If you could postpone one weekly task, which one would you choose?
4. Which appliance first if it working tomorrow?
Even with tomorrow, use Past Simple after if because the situation is hypothetical.
Which appliance would you replace first if it stopped working tomorrow?

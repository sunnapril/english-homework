1. Zero or first conditional?

Choose the meaning first. Zero conditional describes facts and usual results; first conditional describes a real future possibility.

Zero conditional

if / when + present → present

When people work from home, they often take fewer breaks.

First conditional

if + present → will / might / can + verb

If the delivery arrives today, I’ll install the device tonight.

Important: use present after if: If I have time…, not If I will have time…. Unless means if not.

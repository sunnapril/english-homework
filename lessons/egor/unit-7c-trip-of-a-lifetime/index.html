05 · 12 min

Why? Expressing purpose

to + verb — I went to Tokyo to see the cherry blossoms.
in order to + verb (more formal) — Please arrive early in order to finish the registration.
negative: in order not to — We left at 5 a.m. in order not to miss the sunrise.
so (that) + clause, often with can / could / will / would — I downloaded the maps so that I could use them offline. Use it when the subject changes: I’ll text you the address so that you don’t get lost.
for + noun — She went to the pharmacy for some plasters.
for + -ing = what a thing is used for — A head torch is for walking in the dark.
✗ I went to the shop for buying bread. → ✓ to buy bread / for bread
Pronunciation: to /tə/, for /fə/, that /ðət/ are not stressed.

Say it another way

Complete the second sentence so that it means the same. Use the word in brackets.

1I’m taking a power bank because I want to use my phone as a map.
→ I’m taking a power bank ___ my phone as a map. (so that)
so that + subject + can …
so that I can use
2We booked early because we wanted cheaper tickets.
→ We booked early ___ cheaper tickets. (order)
in order to + verb
in order to get
3He whispered because he didn’t want to wake the baby.
→ He whispered ___ the baby. (so that)
Negative + past: so that he wouldn’t …
so that he wouldn’t wake
4I use this app because it helps me learn words.
→ I use this app ___ words. (for)
What is the app for? for + -ing
for learning
5We left at six because we didn’t want to get stuck in traffic.
→ We left at six ___ stuck in traffic. (order)
Negative: in order not to …
in order not to get

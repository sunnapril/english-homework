5 · Structure · 6 min

Read every requirement in the question

Question: Your friend wants to join an evening course. Which option would you recommend? Mention two advantages and one disadvantage.

A complete answer needs:

  1. a clear recommendation;
  2. advantage 1 + supporting reason;
  3. advantage 2 + supporting reason;
  4. one disadvantage;
  5. a short conclusion.
I would recommend … . The first advantage is … because … . Another advantage is … . The main disadvantage is … . On balance, … .
6 · Upgrade · 8 min

Build a stronger answer

On balance = after considering both advantages and disadvantages.

Main idea: the smaller evening class gives students more speaking time. Add precise evidence, a second advantage and a real disadvantage.
Recommendation:
Two advantages + evidence:
One disadvantage + conclusion:
I would recommend the smaller evening class. The first advantage is that each student would have more time to speak because there are fewer people in the group. Another advantage is that the teacher could give more individual feedback. The main disadvantage is that this option is slightly more expensive. On balance, I think the extra speaking practice would make it the better choice.
7 · Professional advice · 9 min

From concern to recommendation

Use four supports: main concern → consequence → suggestion → reason.

Situation A. A client regularly sends invoices after the monthly closing deadline.
Main concern
Possible consequence
Suggestion + reason
The main concern is that late invoices may make the monthly report incomplete. This could delay the closing process. I would suggest agreeing on a fixed deadline with the client and sending a reminder two days before it.
Situation B. Three colleagues are editing different versions of the same quarterly report.
Main concern
Possible consequence
Suggestion + reason
The main concern is that the team may use outdated figures. This could lead to errors in the final report. I would suggest creating one shared file and giving one person responsibility for the final version.

2Complete the grammar map 12 min

ZERO CONDITIONAL — habits & general results
if / when + Present Simple → Present Simple
When I buy fresh mushrooms, I cook them the same day.
when works well when the situation is expected/repeated: “every time this happens”.
FIRST CONDITIONAL — a real future possibility
if / unless + Present Simple → will / can / may / might + infinitive
If the weather is good tomorrow, we might go to the market.
Unless I finish late, I’ll call you. = If I don’t finish late, I’ll call you.
One rule to protect: no will in the condition after if / unless / when.
✓ If she has time, she’ll come.   ✗ If she will have time…

Vocabulary Bank · production

Choose a verb and build a complete answer

You do not need to use every verb.

1. A small company mainly develops security software for hospitals. Describe its area of expertise.
Start with The company... and use a verb followed by in + -ing.
Show a possible answer after discussion

The company specialises in developing security software for hospitals.

2. A colleague wants to publish an unfinished report. You believe this could damage the company’s reputation. Explain what you would advise.
Use discourage someone from + -ing and explain when publication would be safer.
Show a possible answer after discussion

I’d discourage him from publishing the report until all the figures had been checked.

Vocabulary in conversation

Respond naturally and precisely

1. Your colleague wants to remove an old project folder immediately. You think the team may still need some of the files later. Reply using you never know or just in case.
You never know introduces an uncertain future possibility. Just in case explains a precaution.
Show two possible answers

Let’s keep the folder for another month. You never know when we might need one of those files.

I’d save a copy just in case a client asks about the old version.

2. A manager has chosen a new system without asking the people who will use it every day. Explain the problem using impose something on someone.
Pattern: impose + decision/system/rule + on + person/group.
Show a possible answer

The manager imposed the new system on the team without asking whether it would work in practice.
